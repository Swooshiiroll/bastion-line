Layout. The trunk sits on the left; the three branches run left to right as rows, each ending in its mastery. The panel grows from 700 to 1100 px wide to fit five nodes per branch.
Status strip. The header says which branch is primary and how far along each one is, so the lock-in rule is visible before you commit.
Secondary cap. A marker after the second upgrade shows where a secondary stops. Once a branch reaches its third upgrade, the other started branch greys out beyond what it owns.
Details. Hovering any node shows its description and the tower's stats before and after, including what the other branch contributes.
Bottom bar. The selected-tower card shows the same three branches as a compact strip (A ●●●○ M, B ●● cap, C locked), and its buttons buy the next upgrade on each branch.
